
# Курсовая работа о получении данных о самолетах в воздушных пространствах и загрузка полученных данных в таблицы
# Описание проекта
Программа автоматически определяет географические границы (Bounding Box) выбранных европейских стран, собирает данные о самолетах в их воздушном пространстве и сохраняет историю наблюдений в базу данных PostgreSQL.

# Используемые технологии и API
Python 3 — основной язык разработки.
PostgreSQL — система управления базами данных (СУБД).
Библиотеки Python: requests (для HTTP-запросов), psycopg2 (для взаимодействия с PostgreSQL).
Nominatim API (OpenStreetMap) — получение географических координат границ стран.
OpenSky Network REST API — получение данных о текущем положении, скорости и позывных воздушных судов.

# Структура проекта
config.py — конфигурационный файл (параметры подключения к БД, список отслеживаемых стран, настройки заголовков API),
api_client.py — сбор данных из внешних API OpenSky и Nominatim,
database.py — основной модуль с методами соединения с базой данных, создания таблиц и сбора данных,
main.py — запуск программы и вывод данных в консоль,
requirements.txt — список внешних зависимостей проекта.

# Архитектура базы данных
В БД создаются две связанные таблицы:
1. countries — хранит названия стран и координаты их ограничивающих прямоугольников (`lamin`, `lomin`, `lamax`, `lomax`).
2. flights — хранит зафиксированные данные о самолетах (`icao24`, `callsign`, `longitude`, `latitude`, `velocity`, `on_ground`, `last_contact`, `captured_at`), привязанные к стране через внешний ключ `country_id`.

# Запуск программы
python main.py
